# Global Crisis Monitor

Interactive geospatial crisis-monitoring dashboard built with HTML, CSS, JavaScript, Leaflet, and OpenStreetMap.

## Features

- Interactive global GIS map
- Clickable severity-scaled crisis markers
- Search and category/severity/status filters
- Live KPI cards based on the filtered view
- Crisis intelligence detail panel
- Interactive crisis feed
- Category distribution visualization
- Responsive desktop/mobile interface

## Important data note

The initial records in `data.js` are **sample demonstration records**, not a live intelligence feed. They are intentionally separated from the application logic so verified records and APIs can replace them later.

## GitHub Pages

The project is static-site compatible. Publish the repository's `main` branch from the root directory using GitHub Pages.
