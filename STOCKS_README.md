# Stock Universe Monitor

A companion dashboard to the Global Crisis Monitor.

Open `stocks.html` to use an interactive personal stock-research dashboard with:

- Risk vs. reward bubble chart
- Bubble size based on conviction
- Bubble color based on watchlist status
- Manual stock idea entry
- Filters for sector, status, and time horizon
- Clickable detail panel for thesis and catalysts
- Sector breakdown
- Stock watchlist table

The included records are example ideas for interface demonstration only. They are not live prices, recommendations, or financial advice.
